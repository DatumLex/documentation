## Presentation Working Agreement

- Add the correct Google Slides, PDF, or PowerPoint link for each sprint as
  soon as the presentation is created.
- Keep each sprint presentation separate; do not overwrite a previous sprint
  deck with a new one.
- Include the Sprint Goal, delivered backlog items, demonstration evidence,
  validation results, known limitations, and next steps.
- Link the relevant GitHub Project items and Pull Requests when they help
  reviewers trace the delivery.
